## 1. 语言定位与设计原则

Ada-D 是面向 AI 代码生成的**动态类型脚本语言**，语法遵循"低困惑度"原则：只使用 LLM 高频见过的形式（类 Rust / TypeScript / Python 的交集），不发明冷门符号。

四条硬性原则（改动语法时须遵守）：

1. **Token 密度优先**：无强制分号、单行函数 `fn f(x) = expr`、末尾表达式隐式返回、`mut` 一行声明可变。
2. **表达式优先**：`if`、`match`、块 `{ ... }` 都有值。
3. **安全导航**：`?.` 与 `??` 消除多层判空分支。
4. **零类型负担**：类型标注可选，且当前**仅作语法保留，不做任何检查**（见 §10）。

## 2. 词法 (Lexical)

### 2.1 关键字与保留字 ✅

| 类别 | 记号 |
| :--- | :--- |
| 声明 | `let`、`mut`、`fn`、`async` |
| 异步 | `await`、`spawn` |
| 控制流 | `if`、`else`、`match`、`while`、`for`、`in`、`return`（别名 `ret`）、`break`、`continue` |
| 字面量 | `true`、`false`、`nil`（别名 `null`） |

### 2.2 标识符 ✅

`[A-Za-z_]` 起始，后续 `[A-Za-z0-9_]`。无 Unicode 标识符。

### 2.3 注释 ✅

- 行注释：`// ...` 至行尾
- 块注释：`/* ... */`，**不支持嵌套**；未闭合报 `LexError::UnterminatedBlockComment`

### 2.4 数值字面量

| 形式 | 状态 | 说明 |
| :--- | :--- | :--- |
| 十进制整数 `123` | ✅ | 支持下划线分隔 `1_000_000` |
| 十六进制 `0xFF` | ✅ | 支持下划线 |
| 二进制 `0b1010` | ✅ | 支持下划线 |
| 浮点 `1.5` | ✅ | 小数点是进入浮点模式的唯一入口 |
| 科学计数 `1.0e5` / `1.0E-3` | ✅ | 仅在已出现小数点后被识别 |
| `1e5` | ⚠️ | **不支持**：缺小数点时 `e5` 被切成标识符 → 语法错误（任务 T3.7 边界测试覆盖） |
| 八进制 | ❌ | 不做 |

### 2.5 字符串字面量

- 普通字符串 `"..."` ✅：转义 `\n \t \r \\ \" \0`，其余 `\x` 保留原字符。
- 插值字符串 `$"...{expr}..."` ✅：`{` 开始代码片段，内部支持嵌套花括号计数；转义额外支持 `\{`。
  - ⚠️ **已知缺陷（T3.4）**：每个 `{...}` 片段会被**独立重新解析**，片段内的行列号相对片段自身，因此片段内报错的行列位置不准。
  - ⚠️ **已知限制（T3.7）**：片段内的字符串字面量中含 `}` 时不参与花括号计数，属未定义边界。

### 2.6 换行自闭合与 ASI ✅

词法器在换行处**仅当上一记号可以结束语句**时插入 `Newline` 记号：`Int/Float/String/InterpString/Bool/Nil/Ident/) / ] / } / return / break / continue`。

表达式可在下列记号**之前**跨行续写（`is_continuation_op`）：

```
|>   ??   .   ?.   +   -   *   /   %   &&   ||
```

因此：

```ada
let total = arr
    |> sum()          // 合法：续写算子前换行

let x = 1
    + 2               // 合法：+ 是续写算子
```

⚠️ 注意：`=`、`==`、`<`、`,` 等**不是**续写算子，跨行书写需用括号或把算子放在上一行行尾（T3.7 补测试固化）。

### 2.7 标点与运算符记号 ✅

```
+ - * / %  = == != < <= > >=  ! && ||  & | ^ ~  << >>
+= -= *= /= %=   |>   ??   ?.   =>   ->
( ) [ ] { } , : . ;
```

`?` 单独出现是词法错误（仅 `??`、`?.` 合法）。

## 4. 表达式与优先级

### 4.1 优先级表（与实现严格一致）✅

数字越大绑定越紧。实现位于 `crates/ada_parser/src/parser.rs` 的 `Precedence` 枚举。

| 级别 | 名称 | 记号 |
| :--- | :--- | :--- |
| 0 | Lowest | — |
| 1 | Assign | `=` `+=` `-=` `*=` `/=` `%=` |
| 2 | NullCoalesce | `??` |
| 3 | LogicalOr | `\|\|` |
| 4 | LogicalAnd | `&&` |
| 5 | BitOr | `\|` |
| 6 | BitXor | `^` |
| 7 | BitAnd | `&` |
| 8 | Equality | `==` `!=` |
| 9 | Relational | `<` `<=` `>` `>=` |
| 10 | Shift | `<<` `>>` |
| 11 | Term | `+` `-` |
| 12 | Factor | `*` `/` `%` |
| 13 | **Pipe** | `\|>` |
| 14 | Unary | 前缀 `-` `!` `~` `await` `spawn` |
| 15 | Call | `()` `[]` `.` `?.` |

### 4.2 两个必须记住的反直觉点 ✅

1. **管道 `|>` 比 `+`/`*` 结合更紧**：
   `1 + 2 |> f()` 等价于 `1 + (2 |> f())`（实测 `f(x)=x*10` 时结果为 `21`，不是 `30`）。
   写多步管道时请**整体加括号或用换行缩进**，不要与算术混写。
2. **链式赋值不支持**：`a = b = 5` 报 `InvalidAssignmentTarget`（赋值解析为左结合，左侧第二次赋值目标不是标识符/索引/字段）。
   派生后果：`a += b += 1` 同样非法。⚠️ 该行为未进规范文字前属实现细节（任务 T3.7 固化测试）。

### 4.3 结合性

- 前缀一元：右结合，操作数以 Unary(14) 优先级解析，故 `-a * b` = `(-a) * b`、`!a == b` = `(!a) == b` ✅
- ⚠️ `spawn` 同属前缀一元（Unary(14)），因此：
  - `spawn f(1) + 2` = `(spawn f(1)) + 2`（`+` 是 11 级，不进入操作数）
  - 但 `spawn f(1).await` = `spawn (f(1).await)`（`.await` 是 Call(15) 级，**会**进入操作数）。
    想表达"spawn 后再等待"请写两行：`let t = spawn f(1)` / `t.await`
- `??`、`|>`、二元算术/比较：左结合（由 `prec >= next_prec` 的循环条件决定）✅
- 赋值：**不形成链**（见 §4.2）✅

### 4.4 管道脱糖规则 ✅

```
x |> f(a, b)   →   f(x, a, b)     // 右侧是调用：插为首参
x |> f         →   f(x)           // 右侧非调用：作为唯一参数调用
```

`|>` 只做语法脱糖，不引入惰性；`sum()` 等全局函数因此可以直接被管道调用。

## 5. 语句与声明

### 5.1 变量绑定

```ada
let a = 1            // 不可变绑定（语义见下）
mut b = 2            // 可变
let mut c = 3        // 等价写法
let d: int = 4       // 类型标注（当前不校验）
let e                // 无初始化 → nil
```

| 规则 | 状态 | 说明 |
| :--- | :--- | :--- |
| `let` 不可变性 | ✅ | **编译期强制**（T3.1）：`let a = 1; a = 2` 报 `Cannot assign to immutable variable`；容器内容仍可变（`let a = [1]; a.push(2)` 合法） |
| 块级作用域 | ✅ | `{ let x = 1 }` 后 `x` 不可见 |
| 同名遮蔽 | ✅ | 内层 `let` 遮蔽外层，解析取最近声明 |
| 顶层声明跨帧持久 | ✅ | 模块顶层的 `let`/`mut` 同时写入全局表，因此在同一 `Engine`/REPL 中跨轮可见（T2.4）；**函数体内的局部变量不会外泄**。⚠️ 若该变量同时被闭包捕获，全局镜像不随后续写入同步（缺口 G-L16） |

### 5.2 函数

```ada
fn add(x, y) = x + y                 // 单行表达式体，表达式即返回值
fn fib(n) {                          // 块体，末尾表达式隐式返回
    if n <= 1 { n } else { fib(n - 1) + fib(n - 2) }
}
fn scale(val: num, factor: num): num = val * factor   // 类型标注保留但不校验
async fn fetch(id) { ... }           // 异步函数（语义见 SPEC_ASYNC）
```

- 参数列表支持尾随逗号与跨行 ✅
- `return expr` / `ret expr`：提前返回 ✅；`return` 无值返回 `nil` ✅
- 隐式返回：块的最后一条**无分号**表达式语句成为块值 ✅
- ⚠️ 函数体未执行到任何返回且非末尾表达式时返回 `nil`
- ⚠️ 函数内 `break`/`continue` 若不在循环内**静默忽略**（不报错）；闭包体内部的 `break` 无法作用于外层循环（任务 T3.7）

### 5.3 控制流

```ada
while cond { ... }                     // cond 为真值判定
for item in iterable { ... }           // 迭代协议见 SPEC_STDLIB §5
for [k, v] in map { ... }              // 解构
if cond { a } else if cond2 { b } else { c }   // 表达式，有值
```

- `break` ✅ / `continue` ✅（`continue` 在 `for` 中回到 `IterNext`，在 `while` 中回到条件求值）
- 三元：无 `?:`，用 `if` 表达式替代 ✅

### 5.4 表达式语句

任意表达式可作语句，末尾可选 `;`（分号不改变语义，仅用于显式分隔）✅

### 5.5 索引与长度语义

| 表达式 | 状态 | 语义 |
| :--- | :--- | :--- |
| `arr[i]` | ✅ | `i` 必须为非负整数；越界或负数 → `nil`（不报错） |
| `arr[i] = v` | ✅ | 越界/负数 → `IndexOutOfBounds` 运行时错误 |
| `str[i]` | ✅ | **按 Unicode 字符**索引（非字节）；越界或负数 → `nil` |
| `str[i] = v` | ❌ | 字符串不可变，报 `TypeError` |
| `map[key]` | ✅ | 键不存在 → `nil`；`map[key] = v` 新增或覆盖 |
| `len(v)` / `v.len`（字符串） | ✅ | 字符数（= Unicode 标量个数）；字节数用 `v.len_bytes` |
| `v.slice(start, end)`（字符串） | ✅ | 按字符切片，**支持负索引**（从末尾计），越界自动夹取 |

> ✅ 负索引（T3.5，决策已定）：字符串与数组的读索引都支持从末尾计数，越界读返回 `nil`；数组的写索引同样支持负索引，越界时报 `IndexOutOfBounds`。这与 `.slice` 的负索引语义一致。
> 该语义在 0.1.0 曾因按字节切片而在多字节字符串上 panic（缺口 G-L12），已于 M1 修复。

### 5.6 块表达式与 map 简写的区分 ✅（T3.3，决策 D4）

`{}` 在本语言中是 **map 字面量**（支持 `{ name }` 简写），块表达式只在语句位置出现。判定规则：

| 写法 | 解析结果 |
| :--- | :--- |
| `{ x }`、`{ x, y }` | **map**（键 `x`/`y` 简写，取同名变量的值） |
| `{ let a = 1; a + 1 }` | **块表达式**（以语句开头），末尾表达式即块值 |
| `if cond { x } else { y }`、`fn f() { x }` | 块（由 `if`/`fn` 语法直接解析，不存在歧义） |

因此需要"把某个变量原样作为表达式"时不要写 `{ x }`，直接用 `x` 或 `(x)`。

```ada
let x = 5
type_of({ x })          // "map"
{ x }.x                 // 5
let v = { let a = 1
    a + 1 }             // 块：v == 2
```

## 6. 闭包 (Closures)

```ada
let f = x => x + 1                 // 单参
let g = () => 42                   // 零参
let h = (a, b) => a * b            // 多参
let k = (x) => x * 2               // 单参（带括号）
```

| 能力 | 状态 | 说明 |
| :--- | :--- | :--- |
| 作为值传递、被 `|>` 管道调用 | ✅ | |
| 捕获自身参数 | ✅ | |
| **捕获外层局部变量（upvalue）** | ✅ | `fn outer(a) { let g = x => x + a; g(5) }` → `15`；捕获为**引用共享**（见下） |
| 在闭包内写入外层变量 | ✅ | `mut n = 0; let inc = () => { n += 1 }`：外层读到修改后的值 |
| 多级传递捕获（中间层不引用也可） | ✅ | `fn l1() { let x = 10; fn l2() { fn l3() = x + 5; l3() }; l2() }` → `15` |
| 闭包逃逸定义作用域 | ✅ | 返回的闭包继续持有捕获槽（`fn mk(n) { x => x + n }`） |
| 循环变量捕获 | ✅ | **每轮独立槽**：`for i in range(0,3) { grabs.push((() => i)) }` → `[0, 1, 2]` |
| 内层参数遮蔽外层同名变量 | ✅ | 内层参数优先 |
| 递归闭包（自引用） | ⚠️ | 箭头闭包无法引用自身；顶层/函数体内的具名 `fn` 通过全局名递归（缺口 G-L15） |
| 显式返回类型/参数类型标注 | ❌ | 闭包语法不支持类型标注 |

### 6.1 捕获语义（T2.2）✅

1. **引用共享**：被闭包捕获的局部变量由编译器装箱为可共享的变量槽（Cell），闭包与外层函数读写**同一个槽**，因此"计数器"惯用法成立。
2. **装箱判定**：编译期为每个函数预扫描"其嵌套函数中出现过的标识符"，命中同名局部变量即装箱。这是**上近似**（可能多装箱，但不会漏），因此不改变语义、只影响少量性能。
3. **循环变量**：`for` 的循环变量在被捕获时**每轮重新装箱**，所以每次迭代的闭包持有各自独立的槽（类 JS `let`，而非 `var`）。
4. **多级嵌套**：捕获链会逐层传递，中间函数即使不直接引用该变量也能把槽传下去。
5. ⚠️ **顶层变量与全局镜像**：模块顶层的绑定会同时写入全局表（T2.4）。若该变量**同时被闭包捕获**，全局表里存的是定义时的值快照；闭包后续对槽的修改**不会**同步回全局表。同一脚本内始终走局部槽（行为正确），只有"写入后由后续 REPL 求值再读取"才可能看到旧值（缺口 G-L16）。

## 7. 模式匹配 (Match)

```ada
let grade = match score {
    >= 90 => "A",
    >= 80 => "B",
    _     => "C"
}

let r = match value {
    n if n > 10 => "big",     // guard
    0 | 1 => ...              // ❌ 不支持或模式
}
```

| 模式 | 状态 | 说明 |
| :--- | :--- | :--- |
| `_` 通配 | ✅ | |
| 标识符绑定 `n` | ✅ | 绑定到目标值；⚠️ 绑定作用域在编译器中不回收（任务 T3.7） |
| 字面量 `1` / `"s"` / `true` / `nil` | ✅ | ⚠️ **大整数**在编译期被截断为 `i32`（任务 T3.7/D5） |
| 比较 `>= > <= <` | ✅ | 仅这四种，右侧表达式以 Equality 优先级解析 |
| guard `pattern if cond` | ✅ | |
| 或模式 `a | b` | ❌ | 不做（拆成多个 arm） |
| 范围/解构/类型模式 | ❌ | 不做 |
| 非穷尽检查 | ✅ | **无匹配时抛运行时错误**（T3.2，决策 D7 = 报错）：`VmError::NoMatch`，不再留下未赋值的目标。`_` 与无 guard 的标识符绑定视为兜底 arm |

arm 体可以是表达式或块；arm 之间用换行或 `,` 分隔。

## 8. 安全导航与空值合并

```ada
let timeout = cfg?.meta?.timeout ?? 5000
let name = user?.profile?.email ?? "guest"
```

| 表达式 | 目标类型 | 状态 | 语义 |
| :--- | :--- | :--- | :--- |
| `a?.b` | `nil` | ✅ | 求值为 `nil`（不报错） |
| `a.b` | `nil` | ✅ | 报 `VmError::TypeError("Cannot access property 'b' on nil")` |
| `a.b` | `int` 等非 map/array/string | ⚠️ | **静默返回 `nil`**，不报错（`(5).foo` → `nil`） |
| `a.b` | `map` | ✅ | 键存在则取值，否则 `nil` |
| `a ?? b` | 任意 | ✅ | `a` 为 `nil` 时取 `b`，否则取 `a`；左结合 |

⚠️ "字段不存在返回 `nil`" 与"类型不对返回 `nil`"混在一起，容易掩盖 bug；任务 T3.7 将补测试并在规范中明示（是否改为报错由决策 D4 相关讨论决定）。

## 9. 相等与真值语义

### 9.1 相等 `==` / `!=`（实测口径）✅

| 操作数 | 规则 |
| :--- | :--- |
| `int` × `int` / `float` × `float` | 数值比较 |
| `int` × `float` | 提升为 `float` 后比较 |
| `string` × `string` | 内容比较 |
| `array` × `array` | **引用（`Arc` 指针）相等**：`[1,2] == [1,2]` 为 `false`；同一变量比较为 `true` |
| `map` × `map` | 引用相等（同上） |
| `function` × `function` | 闭包按原型指针，原生函数按名字 |
| `task` × `task` | 引用相等或其内部值相等 |
| 不同类型 | `false`（不报错） |

> ⚠️ 结构化相等（深比较）**不存在**；需要比较内容时必须显式 `json.stringify(a) == json.stringify(b)` 或逐元素比较。任务 T3.7 补文档化测试。

### 9.2 真值 (truthiness) ✅

| 值 | 真值 |
| :--- | :--- |
| `nil` | false |
| `false` | false |
| `0` / `0.0` / `NaN` | false |
| `""` | false |
| 非空字符串、任意数组、任意 map、函数、task、iterator | true |

### 9.3 有序比较 `<` `<=` `>` `>=` ✅（T3.5）

- **只接受数值操作数**（`int` / `float` 可混合比较）；其它类型报 `TypeError`，不再静默返回 `false`。
  理由：`if user.age > 18` 这类动态数据上的静默 `false` 是最难排查的 bug 来源之一。
- `NaN` 遵循 IEEE-754：与任何值的有序比较都为 `false`。
- 相等 `==` / `!=` 不受此限制（见 §9.1），类型不同即为 `false`。

```ada
1 < 2.5            // true
5 < "a"            // TypeError: Cannot compare ...
nil > 0            // TypeError
(0.0 / 0.0) < 1.0  // false（NaN）
```

### 9.4 浮点数与整数的输出差异 ✅（T3.6）

- 整数值的浮点保留小数位：`to_str(1.0)` → `"1.0"`，与 `to_str(1)` → `"1"` 可区分。
- 极大/极小值使用科学计数法（`1e300`、`1e-300`），避免打印出数百位数字。
- 整数除零报错，浮点除零遵循 IEEE（`1.0 / 0.0` → `inf`）：整数语义精确、浮点语义符合 IEEE-754。

## 1. 语言定位与设计原则

Ada-D 是面向 AI 代码生成的**动态类型脚本语言**，语法遵循"低困惑度"原则：只使用 LLM 高频见过的形式（类 Rust / TypeScript / Python 的交集），不发明冷门符号。

四条硬性原则（改动语法时须遵守）：

1. **Token 密度优先**：无强制分号、单行函数 `fn f(x) = expr`、末尾表达式隐式返回、`mut` 一行声明可变。
2. **表达式优先**：`if`、`match`、块 `{ ... }` 都有值。
3. **安全导航**：`?.` 与 `??` 消除多层判空分支。
4. **零类型负担**：类型标注可选，且当前**仅作语法保留，不做任何检查**（见 §10）。

## 2. 词法 (Lexical)

### 2.1 关键字与保留字 ✅

| 类别 | 记号 |
| :--- | :--- |
| 声明 | `let`、`mut`、`fn`、`async` |
| 异步 | `await`、`spawn` |
| 控制流 | `if`、`else`、`match`、`while`、`for`、`in`、`return`（别名 `ret`）、`break`、`continue` |
| 字面量 | `true`、`false`、`nil`（别名 `null`） |

### 2.2 标识符 ✅

`[A-Za-z_]` 起始，后续 `[A-Za-z0-9_]`。无 Unicode 标识符。

### 2.3 注释 ✅

- 行注释：`// ...` 至行尾
- 块注释：`/* ... */`，**不支持嵌套**；未闭合报 `LexError::UnterminatedBlockComment`

### 2.4 数值字面量

| 形式 | 状态 | 说明 |
| :--- | :--- | :--- |
| 十进制整数 `123` | ✅ | 支持下划线分隔 `1_000_000` |
| 十六进制 `0xFF` | ✅ | 支持下划线 |
| 二进制 `0b1010` | ✅ | 支持下划线 |
| 浮点 `1.5` | ✅ | 小数点是进入浮点模式的唯一入口 |
| 科学计数 `1.0e5` / `1.0E-3` | ✅ | 仅在已出现小数点后被识别 |
| `1e5` | ⚠️ | **不支持**：缺小数点时 `e5` 被切成标识符 → 语法错误（任务 T3.7 边界测试覆盖） |
| 八进制 | ❌ | 不做 |

### 2.5 字符串字面量

- 普通字符串 `"..."` ✅：转义 `\n \t \r \\ \" \0`，其余 `\x` 保留原字符。
- 插值字符串 `$"...{expr}..."` ✅：`{` 开始代码片段，内部支持嵌套花括号计数；转义额外支持 `\{`。
  - ⚠️ **已知缺陷（T3.4）**：每个 `{...}` 片段会被**独立重新解析**，片段内的行列号相对片段自身，因此片段内报错的行列位置不准。
  - ⚠️ **已知限制（T3.7）**：片段内的字符串字面量中含 `}` 时不参与花括号计数，属未定义边界。

### 2.6 换行自闭合与 ASI ✅

词法器在换行处**仅当上一记号可以结束语句**时插入 `Newline` 记号：`Int/Float/String/InterpString/Bool/Nil/Ident/) / ] / } / return / break / continue`。

表达式可在下列记号**之前**跨行续写（`is_continuation_op`）：

```
|>   ??   .   ?.   +   -   *   /   %   &&   ||
```

因此：

```ada
let total = arr
    |> sum()          // 合法：续写算子前换行

let x = 1
    + 2               // 合法：+ 是续写算子
```

⚠️ 注意：`=`、`==`、`<`、`,` 等**不是**续写算子，跨行书写需用括号或把算子放在上一行行尾（T3.7 补测试固化）。

### 2.7 标点与运算符记号 ✅

```
+ - * / %  = == != < <= > >=  ! && ||  & | ^ ~  << >>
+= -= *= /= %=   |>   ??   ?.   =>   ->
( ) [ ] { } , : . ;
```

`?` 单独出现是词法错误（仅 `??`、`?.` 合法）。

## 3. 类型 (Types)

### 3.1 值类型清单 ✅

| 类型名（`type_of` 返回值） | 字面量形式 | 说明 |
| :--- | :--- | :--- |
| `nil` | `nil` / `null` | 空值 |
| `bool` | `true` / `false` | |
| `int` | `123` | 64 位有符号整数 |
| `float` | `1.5` | 64 位 IEEE-754 |
| `string` | `"..."` / `$"..."` | UTF-8；内部为 `Arc<String>`；索引与 `len` 按**字符**计（见 §5.5） |
| `array` | `[a, b]` | 可变、引用语义 |
| `map` | `{k: v}` | 键为字符串，有序性不保证 |
| `function` | `fn` / `x => e` | 闭包或原生函数 |
| `task` | `spawn expr` | 并发任务句柄（当前语义见 [SPEC_ASYNC §3](SPEC_ASYNC.md)） |
| `iterator` | `range(...)` | 惰性迭代器 |

### 3.2 类型标注 ⚠️（不生效）

语法上允许位置：`let a: int = 1`、`fn f(x: num): num = x`。解析后存入 AST 的 `type_ann` / `ret_type`。

**当前不做任何检查**：`let a: int = "str"` 合法且 `type_of(a) == "string"`（实测）。渐进类型与 JIT 类型反馈属 📋（任务 T6.3 / D1）。

### 3.3 类型转换

由标准库函数 `to_int` / `to_float` / `to_str` / `to_bool` 提供，转换规则见 [SPEC_STDLIB §2.3](SPEC_STDLIB.md#23-类型转换)。

## 4. 表达式与优先级

### 4.1 优先级表（与实现严格一致）✅

数字越大绑定越紧。实现位于 `crates/ada_parser/src/parser.rs` 的 `Precedence` 枚举。

| 级别 | 名称 | 记号 |
| :--- | :--- | :--- |
| 0 | Lowest | — |
| 1 | Assign | `=` `+=` `-=` `*=` `/=` `%=` |
| 2 | NullCoalesce | `??` |
| 3 | LogicalOr | `\|\|` |
| 4 | LogicalAnd | `&&` |
| 5 | BitOr | `\|` |
| 6 | BitXor | `^` |
| 7 | BitAnd | `&` |
| 8 | Equality | `==` `!=` |
| 9 | Relational | `<` `<=` `>` `>=` |
| 10 | Shift | `<<` `>>` |
| 11 | Term | `+` `-` |
| 12 | Factor | `*` `/` `%` |
| 13 | **Pipe** | `\|>` |
| 14 | Unary | 前缀 `-` `!` `~` `await` `spawn` |
| 15 | Call | `()` `[]` `.` `?.` |

### 4.2 两个必须记住的反直觉点 ✅

1. **管道 `|>` 比 `+`/`*` 结合更紧**：
   `1 + 2 |> f()` 等价于 `1 + (2 |> f())`（实测 `f(x)=x*10` 时结果为 `21`，不是 `30`）。
   写多步管道时请**整体加括号或用换行缩进**，不要与算术混写。
2. **链式赋值不支持**：`a = b = 5` 报 `InvalidAssignmentTarget`（赋值解析为左结合，左侧第二次赋值目标不是标识符/索引/字段）。
   派生后果：`a += b += 1` 同样非法。⚠️ 该行为未进规范文字前属实现细节（任务 T3.7 固化测试）。

### 4.3 结合性

- 前缀一元：右结合，操作数以 Unary(14) 优先级解析，故 `-a * b` = `(-a) * b`、`!a == b` = `(!a) == b` ✅
- `??`、`|>`、二元算术/比较：左结合（由 `prec >= next_prec` 的循环条件决定）✅
- 赋值：**不形成链**（见 §4.2）✅

### 4.4 管道脱糖规则 ✅

```
x |> f(a, b)   →   f(x, a, b)     // 右侧是调用：插为首参
x |> f         →   f(x)           // 右侧非调用：作为唯一参数调用
```

`|>` 只做语法脱糖，不引入惰性；`sum()` 等全局函数因此可以直接被管道调用。

## 5. 语句与声明

### 5.1 变量绑定

```ada
let a = 1            // 不可变绑定（语义见下）
mut b = 2            // 可变
let mut c = 3        // 等价写法
let d: int = 4       // 类型标注（当前不校验）
let e                // 无初始化 → nil
```

| 规则 | 状态 | 说明 |
| :--- | :--- | :--- |
| `let` 不可变性 | ⚠️ | **当前未强制**：`let a = 1; a = 2` 静默生效（任务 T3.1） |
| 块级作用域 | ✅ | `{ let x = 1 }` 后 `x` 不可见 |
| 同名遮蔽 | ✅ | 内层 `let` 遮蔽外层，解析取最近声明 |
| 顶层声明跨帧持久 | ⚠️ | 函数体内有效；**REPL 跨行不持久**（任务 T2.4） |

### 5.2 函数

```ada
fn add(x, y) = x + y                 // 单行表达式体，表达式即返回值
fn fib(n) {                          // 块体，末尾表达式隐式返回
    if n <= 1 { n } else { fib(n - 1) + fib(n - 2) }
}
fn scale(val: num, factor: num): num = val * factor   // 类型标注保留但不校验
async fn fetch(id) { ... }           // 异步函数（语义见 SPEC_ASYNC）
```

- 参数列表支持尾随逗号与跨行 ✅
- `return expr` / `ret expr`：提前返回 ✅；`return` 无值返回 `nil` ✅
- 隐式返回：块的最后一条**无分号**表达式语句成为块值 ✅
- ⚠️ 函数体未执行到任何返回且非末尾表达式时返回 `nil`
- ⚠️ 函数内 `break`/`continue` 若不在循环内**静默忽略**（不报错）；闭包体内部的 `break` 无法作用于外层循环（任务 T3.7）

### 5.3 控制流

```ada
while cond { ... }                     // cond 为真值判定
for item in iterable { ... }           // 迭代协议见 SPEC_STDLIB §5
for [k, v] in map { ... }              // 解构
if cond { a } else if cond2 { b } else { c }   // 表达式，有值
```

- `break` ✅ / `continue` ✅（`continue` 在 `for` 中回到 `IterNext`，在 `while` 中回到条件求值）
- 三元：无 `?:`，用 `if` 表达式替代 ✅

### 5.4 表达式语句

任意表达式可作语句，末尾可选 `;`（分号不改变语义，仅用于显式分隔）✅

### 5.5 索引与长度语义

| 表达式 | 状态 | 语义 |
| :--- | :--- | :--- |
| `arr[i]` | ✅ | `i` 必须为非负整数；越界或负数 → `nil`（不报错） |
| `arr[i] = v` | ✅ | 越界/负数 → `IndexOutOfBounds` 运行时错误 |
| `str[i]` | ✅ | **按 Unicode 字符**索引（非字节）；越界或负数 → `nil` |
| `str[i] = v` | ❌ | 字符串不可变，报 `TypeError` |
| `map[key]` | ✅ | 键不存在 → `nil`；`map[key] = v` 新增或覆盖 |
| `len(v)` / `v.len`（字符串） | ✅ | 字符数（= Unicode 标量个数）；字节数用 `v.len_bytes` |
| `v.slice(start, end)`（字符串） | ✅ | 按字符切片，**支持负索引**（从末尾计），越界自动夹取 |

> ⚠️ 已知不一致（缺口 G-L14）：字符串索引不支持负索引，但 `.slice` 支持；数组索引也不支持负索引。统一方案由任务 T3.5 决策（选项：全面支持负索引 / 全面禁止并报错）。
> 该语义在 0.1.0 曾因按字节切片而在多字节字符串上 panic（缺口 G-L12），已于 M1 修复。

## 6. 闭包 (Closures)

```ada
let f = x => x + 1                 // 单参
let g = () => 42                   // 零参
let h = (a, b) => a * b            // 多参
let k = (x) => x * 2               // 单参（带括号）
```

| 能力 | 状态 | 说明 |
| :--- | :--- | :--- |
| 作为值传递、被 `|>` 管道调用 | ✅ | |
| 捕获自身参数 | ✅ | |
| **捕获外层局部变量（upvalue）** | ⚠️ | **未实现**：`fn outer(a) { let g = x => x + a; g(5) }` → `UndefinedGlobal("a")`（任务 T2.2） |
| 递归闭包（自引用） | ⚠️ | 无 upvalue 故不可用（T2.2 后支持） |
| 显式返回类型/参数类型标注 | ❌ | 闭包语法不支持类型标注 |

> **重要**：这是当前阻塞 `map`/`filter` 等管道算子真实可用的根因，优先级 P1。

## 7. 模式匹配 (Match)

```ada
let grade = match score {
    >= 90 => "A",
    >= 80 => "B",
    _     => "C"
}

let r = match value {
    n if n > 10 => "big",     // guard
    0 | 1 => ...              // ❌ 不支持或模式
}
```

| 模式 | 状态 | 说明 |
| :--- | :--- | :--- |
| `_` 通配 | ✅ | |
| 标识符绑定 `n` | ✅ | 绑定到目标值；⚠️ 绑定作用域在编译器中不回收（任务 T3.7） |
| 字面量 `1` / `"s"` / `true` / `nil` | ✅ | ⚠️ **大整数**在编译期被截断为 `i32`（任务 T3.7/D5） |
| 比较 `>= > <= <` | ✅ | 仅这四种，右侧表达式以 Equality 优先级解析 |
| guard `pattern if cond` | ✅ | |
| 或模式 `a | b` | ❌ | 不做（拆成多个 arm） |
| 范围/解构/类型模式 | ❌ | 不做 |
| 非穷尽检查 | ⚠️ | **无匹配时静默返回 `nil`**（任务 T3.2 / 决策 D7） |

arm 体可以是表达式或块；arm 之间用换行或 `,` 分隔。

## 8. 安全导航与空值合并

```ada
let timeout = cfg?.meta?.timeout ?? 5000
let name = user?.profile?.email ?? "guest"
```

| 表达式 | 目标类型 | 状态 | 语义 |
| :--- | :--- | :--- | :--- |
| `a?.b` | `nil` | ✅ | 求值为 `nil`（不报错） |
| `a.b` | `nil` | ✅ | 报 `VmError::TypeError("Cannot access property 'b' on nil")` |
| `a.b` | `int` 等非 map/array/string | ⚠️ | **静默返回 `nil`**，不报错（`(5).foo` → `nil`） |
| `a.b` | `map` | ✅ | 键存在则取值，否则 `nil` |
| `a ?? b` | 任意 | ✅ | `a` 为 `nil` 时取 `b`，否则取 `a`；左结合 |

⚠️ "字段不存在返回 `nil`" 与"类型不对返回 `nil`"混在一起，容易掩盖 bug；任务 T3.7 将补测试并在规范中明示（是否改为报错由决策 D4 相关讨论决定）。

## 9. 相等与真值语义

### 9.1 相等 `==` / `!=`（实测口径）✅

| 操作数 | 规则 |
| :--- | :--- |
| `int` × `int` / `float` × `float` | 数值比较 |
| `int` × `float` | 提升为 `float` 后比较 |
| `string` × `string` | 内容比较 |
| `array` × `array` | **引用（`Arc` 指针）相等**：`[1,2] == [1,2]` 为 `false`；同一变量比较为 `true` |
| `map` × `map` | 引用相等（同上） |
| `function` × `function` | 闭包按原型指针，原生函数按名字 |
| `task` × `task` | 引用相等或其内部值相等 |
| 不同类型 | `false`（不报错） |

> ⚠️ 结构化相等（深比较）**不存在**；需要比较内容时必须显式 `json.stringify(a) == json.stringify(b)` 或逐元素比较。任务 T3.7 补文档化测试。

### 9.2 真值 (truthiness) ✅

| 值 | 真值 |
| :--- | :--- |
| `nil` | false |
| `false` | false |
| `0` / `0.0` / `NaN` | false |
| `""` | false |
| 非空字符串、任意数组、任意 map、函数、task、iterator | true |

## 10. 作用域与可见性

| 规则 | 状态 |
| :--- | :--- |
| 块 `{}` / `if` 分支 / `while` 体 / `for` 体引入新作用域 | ✅ |
| 内层可读外层局部变量；函数/闭包体内**不可**读外层局部（无 upvalue） | ⚠️（T2.2） |

| 顶层 `let` 是否成为全局 | ⚠️ 取决于上下文（REPL 不持久，T2.4） |
